# Logistic Regression on Titanic Dataset

##  Project Description
This project demonstrates a complete Machine Learning classification pipeline using the Titanic dataset. The notebook focuses on predicting passenger survival by applying data preprocessing, feature engineering, feature scaling, and multiple classification algorithms.

##  Key Features
- Imported and analyzed the Titanic dataset using Pandas.
- Performed data cleaning and handled missing values.
- Applied feature engineering techniques.
- Encoded categorical variables using Label Encoding and One-Hot Encoding.
- Standardized numerical features using StandardScaler.
- Split the dataset into training and testing sets.
- Built and trained multiple Machine Learning models.
- Evaluated model performance using various classification metrics.

##  Machine Learning Models
- Logistic Regression
- Gaussian Naive Bayes
- Support Vector Machine (SVM)

##  Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score
- Classification Report

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

##  Objective
The primary objective of this project is to build and compare different classification models for predicting passenger survival on the Titanic dataset while following a complete machine learning workflow.
